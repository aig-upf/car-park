# car-park

Repository for the project of car park occupancy models in BCN with ATM.

This repository contains the source code and data to reproduce the numerical experiments of the paper:
- *A Simple and Explainable Model for Park-and-Ride Car Park Occupancy Prediction*.  <br>
  Andreas Kaltenbrunner, Josep Ferrer, David Moreno, Vicenç Gómez, <br>
  EPJ Data Sci. 14, 74 (2025). https://doi.org/10.1140/epjds/s13688-025-00588-0
